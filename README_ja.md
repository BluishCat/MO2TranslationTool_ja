# MO2 Translation Tool 日本語化・改造版（3.0.1-ja.2）

Mod Organizer 2 の中で Mod を翻訳するプラグインです。LLM や機械翻訳を使います。
[InfernoKgn さんの MO2 Translation Tool 3.0.1](https://www.nexusmods.com/skyrimspecialedition/mods/197796) をもとに、日本語 UI の追加、不具合の修正、機能の追加をしました。

- 原作：InfernoKgn（Nexus Mods 197796）
- 改造：BluishCat
- 原作と同じく、コードの大部分は AI の支援で書かれています（AI-Generated Content）。

## 導入

1. `MO2 Translation Tool.py` を MO2 の `plugins` フォルダに入れます（例：`<MO2>/plugins/`）。原作を入れている場合は上書きしてください。両方を同時には使えません。
2. MO2 を起動するか、起動し直します。
3. MO2 のツールメニューから「MO2 Translation Tool」を開きます。

- 必要なもの：Mod Organizer 2（2.5 系で確認）。Python と Qt は MO2 に同梱されているものを使います。
- esp の訳（DSD 形式）を効かせるには、[Dynamic String Distributor](https://www.nexusmods.com/skyrimspecialedition/mods/107676) が必要です。
- 設定、用語集、翻訳キャッシュは、プラグインと同じフォルダに自動で作られます（`MO2 Translation Tool.config.json`、`MO2 Translation Tool.glossary.json`、`translation_cache.json`）。

## 使い方（おすすめの手順）

1. 翻訳元を `en`、翻訳先を `ja`（初期値）にして、バックエンドを選びます（LM Studio、Ollama、DeepL など）。
2. 「出力設定」の **「元の Mod フォルダに直接書き込む」** をオンにします。こうすると MO2 の Mod 一覧が増えません。
3. **「未翻訳と要再翻訳だけ選択」** を押して、「翻訳」を押します。
4. 終わると、ツールが MO2 の表示を更新します（F5 と同じ）。

最初は Mod を1つだけ選んで試し、ゲーム内で効くか確認してから使うのがおすすめです。

## 原作からの主な変更点

### 日本語 UI
- UI 言語に JA を追加し、初期値を日本語にしました。ログ、ダイアログ、MO2 上の説明文も日本語にしました。
- 翻訳先の初期値を日本語にしました。

### 新機能
- **元の Mod フォルダに直接書き込む**：訳を元の Mod の中に追加します。
  - `_japanese.txt`、`_japanese.strings`、DSD 用の json は別名で追加します。同じ名前のファイル（作者の訳など）がすでにあれば上書きせず、その元ファイルは翻訳もしません。
  - MCM の `config.json` は、英語版を `config.json.bak_en` に退避してから上書きします。元に戻すときは、`.bak_en` を `config.json` にリネームしてください。
  - 書いたファイルは `MO2TranslationTool/<Mod名>.json` に記録します。
  - MO2 の `mods` フォルダの外（DLC など）には書き込みません。
- **Mod 一覧の「状態」列**：翻訳済み、要再翻訳（Mod の更新などで元ファイルや訳ファイルが変わった）、日本語あり（作者の訳や他の日本語化 DSD がある）、未翻訳、対象なし、を判定します。
- **「未翻訳と要再翻訳だけ選択」ボタン**
- **Mod ごとに自動保存**：1 Mod ずつ翻訳し、`<出力フォルダ>/<Mod名>_ja` に保存します。
- **全体の進み具合**：複数の Mod を処理しているとき、全体の件数、経過時間、残り時間の目安を表示します。
- **状態での絞り込み**：Mod 一覧の上の「未翻訳／要再翻訳／翻訳済み／日本語あり／対象なし」のチェックで、表示する Mod を切り替えられます（件数つき）。「すべて選択」は表示中の Mod だけを選びます。
- **接続テスト**：API 設定ウィンドウの「接続テスト」で、接続・モデル一覧・試訳を確認できます。翻訳開始時にも接続を確認し、つながらなければ理由を表示して止まります。
- **完了通知**：翻訳が終わると、音とダイアログ（タスクバーの点滅つき）で知らせます。「完了したら音とダイアログで知らせる」でオフにできます。
- **既存の日本語訳ファイルへのマージ**：`Interface/Translations` の英語ファイルと対になる `_japanese.txt` が既にあり、英語側にだけあるキーがある場合（Mod の更新で項目が増えたときなど）、足りないキーだけを翻訳して日本語ファイルの末尾に追記します。
  - 判定はファイルの行数ではなく `$KEY` 単位です（大文字小文字は区別しません）。既存の行は変えず、日本語側にしかないキーも残します。
  - 「状態」列に「キー不足 N」と表示し、未翻訳として選択の対象になります。
  - 「元の Mod フォルダに直接書き込む」では、元の日本語ファイルを `<名前>.txt.bak_ja` に退避してから追記します。取り消すと元に戻ります。出力フォルダに保存する場合は、追記済みの完全な日本語ファイルを書き出します。
  - 同じキーで英語の文言だけが変わった場合は検出できません。BSA 内の訳ファイルも対象外です。
- **スクリプト（.pex）の表示用の文字列（実験的・初期設定はオフ）**：「スクリプト（.pex）の表示用の文字列も翻訳する」をオンにすると、Papyrus スクリプトに直接書かれた英語のうち、画面に出るものだけを翻訳します。
  - 対象：MCM の `AddToggleOption` / `AddTextOption` / `AddSliderOption` / `SetInfoText` / `ShowMessage` などと、`Debug.Notification` / `Debug.MessageBox` に渡される文字列です（`"Count: " + n` のような連結も含みます）。
  - 訳文は .pex の文字列表の末尾に追加し、その呼び出し箇所の参照だけを差し替えます。元の英語は残るので、同じ文字列をイベント名・キー・比較に使っている処理には影響しません。
  - ページ名、配列（メニューの選択肢など）、変数を経由する文字列、識別子やパスのような文字列は訳しません。BSA 内の .pex も対象外です。
  - 「元の Mod フォルダに直接書き込む」では、英語版を `<名前>.pex.bak_en` に退避してから上書きします。

### 安全策
- 初期設定で翻訳するのは、画面に表示される文章だけを持つ形式に限りました（`.strings`、`Interface/Translations` の txt、MCM の `config.json`、esp は DSD 形式で出力）。
  - ini、その他の json、xml、esp の直接書き換えは、「危険な形式も対象にする」をオンにしたときだけ使えます。SPID、KID、FLM の設定や SKSE プラグインの設定値が翻訳されて壊れるのを防ぐためです。
- MCM の `config.json` は、表示用のキー（`text`、`help`、`displayName` など）だけを訳します。`$KEY` の参照や識別子（`modName`、`id`、`function` など）は触りません。
- すでに翻訳先の言語（かな・漢字）を含む行は、LLM に送りません。翻訳専用モデル（PLaMo など）が日本語を英語に訳し戻してしまうのを防ぐためです。
- 翻訳元にするのは、翻訳元の言語（英語）のファイルだけにしました。
- DSD 出力では、本体・DLC・Creation Club のレコードを上書きしたものは出力しません（公式の日本語訳を残すため）。別の Mod の日本語 DSD がすでにある esp も翻訳しません。
- 翻訳対象が2万行を超えると、続けるか確認します。技術的な行（ID やパスなど）は最初から除外します。

### 不具合の修正
- 文字列の収集で `name 'enc' is not defined` が出て止まる。
- JSON（MCM）の訳がファイルに書き込まれない。
- 翻訳中に MO2 が落ちる（翻訳スレッドから画面を書き換えていた）。
- DSD 形式の出力が作られない。上書きレコードの FormID の指定を誤る（DSD のログに `Couldn't find formID` が出る）。
- `Interface/Translations` の txt に BOM が付かず、ゲームで読まれない（BOM 付きの UTF-16 LE で出力するように修正）。
- 出力に余計な `Data` フォルダの階層ができる。
- アラビア語、ポルトガル語などのファイルまで翻訳元にしてしまう。
- `Docs/` 内の控えや BSA 内のプラグインまで翻訳してしまう。
- キャンセルが効かない（LLM の応答待ち中、文字列の収集中、プレースホルダーの自動修正中）。
- 大量の Mod を選ぶとプレビュー表の作成で固まる（表の作成を高速化）。

## 注意

- 翻訳専用モデル（PLaMo など）は、システムプロンプト（用語集や文体の指示）を読みません。用語集を効かせたい場合は、指示に従えるモデルを使ってください。
- 原作と設定ファイルの名前が同じなので、原作の設定をそのまま引き継ぎます。原作で作った `translation_cache.json` に、日本語を英語に戻した誤訳が入っている場合があります。その行は使われませんが、気になる場合はキャッシュを削除してください。
- 翻訳結果は必ず確認してください。とくに MCM の項目名は、長すぎると画面からはみ出すことがあります。
- .pex の翻訳は実験的な機能です。訳文は UTF-8 で書き込みます。連結される文の断片（`" is female"` など）は単独で訳すため、語順が不自然になることがあります。最初は Mod を1つだけ試し、ゲーム内で表示を確認してください。
